# Genetic characterization of a *P. dactylifera* collection at the National Center for Palms and Dates, Saudi Arabia

We present high-depth whole-genome sequencing of a date palm collection from the National Center for Palms and Dates (NCPD) in Al-Ahsa, Saudi Arabia. This resource comprises 123 female varieties and 131 male accessions, and represents the genetic diversity of *P. dactylifera* in Saudi Arabia.

## Usage

This repository includes:

- The Variant Calling Workflow used to trim raw Illumina sequencing reads, align trimmed reads and filter high quality mapping reads, call and filter SNPs using the high-quality reference genome of Ajwa (https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_051530095.1/);
- The scripts used to detect clones, analyse population structure, generate summary statistics of population genetics, measure genetic distance between NCPD date palms and publicly available *P. dactylifera* varieties, use Neighbor-Joining clustering method.
